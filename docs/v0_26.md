# Velora v0.26 — Enterprise Application Administration

> **Removed.** `velora.app_admin` described below was never used by the application (installed apps are recorded per company by `velora.lifecycle`) and has been removed, with its tests. Kept for history.

## Scope

This release introduces the durable application catalog and tenant-scoped administration records. It provides a foundation for an administrative Desk and controlled lifecycle orchestration.

### Included
- Application catalog registration and discovery.
- Semantic-version validation and minimum Velora version checks.
- Tenant/company-scoped installed application records.
- Dependency compatibility checks against the selected tenant's installed applications.
- Install/upgrade/uninstall records, migration history and audit events.
- A separate SQLite registry database suitable for development and a small single-node deployment.

### Important execution boundary
`ApplicationAdmin.install_record()` records an installation after the caller has successfully run the existing package/lifecycle installer. It does not execute arbitrary package code, run database migrations, or claim that an app is operational. Call the existing lifecycle engine first, then persist the successful result. Failed lifecycle operations should be recorded by the orchestration layer as failed attempts; do not mark them installed.

The v0.26 registry is a control-plane registry, not a replacement for each company's business database. Tenant IDs must come from the authenticated company context; never accept an arbitrary tenant ID from an untrusted client. Enforce System Manager/platform-admin permissions at API boundaries.

## Quick start

```python
from pathlib import Path
from velora.app_admin import ApplicationAdmin

admin = ApplicationAdmin(Path("platform") / "application_registry.db")
admin.register(
    name="accounts",
    title="Accounts",
    version="1.0.0",
    min_velora_version="0.26.0",
    dependencies={},
)

# Run the package lifecycle installer for the currently selected company first.
# Only after it succeeds, record the completed operation:
admin.install_record("company_001", "accounts", "Administrator")
print(admin.tenant_apps("company_001"))
print(admin.migration_history("company_001"))
```
