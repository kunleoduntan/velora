Velora v0.26 Tutorial

Velora v0.26 — Enterprise Application Administration

This tutorial introduces the application catalog and company-scoped installation records.

1. What changes?

Velora can now maintain a central catalog of available applications while recording which applications are installed for each tenant/company. The registry is separate from the company's transactional database.

2. Create the registry

from pathlib import Path
from velora.app_admin import ApplicationAdmin
admin = ApplicationAdmin(Path("platform") / "application_registry.db")

3. Register an application

admin.register(
    name="accounts",
    title="Accounts",
    version="1.0.0",
    min_velora_version="0.26.0",
    dependencies={},
)

4. Check compatibility for a company

result = admin.compatibility("accounts", "0.26.0", "company_001")
if not result["compatible"]:
    print(result["problems"])

5. Record a successful installation

Important: first invoke the existing trusted application lifecycle installer in the selected company's context. Only after it succeeds should the completed installation be recorded below.
admin.install_record("company_001", "accounts", "Administrator")

6. Review installed apps and history

admin.tenant_apps("company_001")
admin.migration_history("company_001")
admin.audit_log("company_001")

7. Upgrade and uninstall

Update the catalog version after validating the new package. Run the existing upgrade lifecycle operation, then record success with operation="upgrade". For uninstall, run the trusted uninstall process first, then call uninstall_record().
