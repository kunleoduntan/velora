# VeloraERP 2.99.0 with framework 1.17.4: Tax Management

New module **Tax Management** inside the ERP (8 doctypes, 3 reports, 6 API routes, 1 daily job): Tax Jurisdiction, Tax Category, Tax Rule (+ bands), Tax Settings, Tax Obligation, Tax Return (+ lines); Tax Ledger, Tax Return Summary and Tax Obligation Calendar reports; a Tax Management hub.

Invoice lines now follow approved Tax Rules by Tax Code. Payroll tax is unchanged.

See TAX-MANAGEMENT-REVIEW.md for the review of the supplied package, the defects fixed and what is not built.
