# Velora 1.16.0
- App Hub in the sidebar; Projects shortcuts merged into one entry.
- Link search faster (permission lookups remembered per request); grid link dropdown no longer clipped.
- Modern dialogs and buttons; Apply to Invoices redesigned.
- Print links carry the company, fixing `CompanyAccessDenied: Select a company to work in` on printing.
- Short document signatures (`velora.signatures`).
- Report screens: row search, fitted columns, dd/mm/yyyy; Excel export redesigned (title, exported-on line, dark-blue header with filters, banded rows, Total records footer).
- Apps declare `required_velora >=1.16.0,<1.17.0`.
