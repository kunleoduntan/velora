VELORA RELEASE 0.41.0

Enterprise Operations & Backup Management

Monitor workspace health and protect workspace files with encrypted backups.

1. Inspect workspace health

velora ops status

Returns a JSON snapshot containing site counts, registered applications, missing application directories, disk capacity and a bounded scan of recent log tails. Credentials and configuration values are not returned.

2. Create an encrypted backup

velora ops backup
# Optional destination:
velora ops backup /secure/location/pre-upgrade.vbackup

The CLI prompts twice for an encryption password (minimum 12 characters). Use a long, unique password and store it separately from the backup.

3. Verify a backup

velora ops verify backups/workspace-YYYYMMDDTHHMMSSZ.vbackup

Verification authenticates and decrypts the archive, then inspects its tar structure without extracting files.

4. Apply retention

velora ops prune --keep 14

Retains the newest 14 `.vbackup` files in the workspace backup directory. Retention must be at least one.

5. Recommended operations routine

velora ops status
velora ops backup
velora ops verify backups/<new-backup>.vbackup
velora ops prune --keep 14

Run a restore rehearsal in a separate staging workspace before relying on a backup for disaster recovery.

Important limitations: This is a workspace file snapshot, not a coordinated live PostgreSQL point-in-time backup. For PostgreSQL databases use Velora's database-aware backup path. This release does not yet provide continuous monitoring agents, notification delivery, automated restore orchestration or recovery-time guarantees.
