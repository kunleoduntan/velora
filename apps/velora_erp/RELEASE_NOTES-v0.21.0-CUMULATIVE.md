# VeloraERP v0.21.0 — Cumulative Release (v0.18.0 to v0.21.0)

This cumulative package includes four consecutive commercial milestones: Sales Order invoicing, Customer Credit Management, Realised Sales Margin, and Sales Returns/Customer Complaints. See the four individual release notes for feature-by-feature scope and limitations.

The release preserves the VeloraERP architecture: Inventory Item is the inventory master, commercial transactions use explicit source-document lineage, financial posting remains in the central Financial Posting Engine, and inventory valuation remains in the Inventory Engine.
