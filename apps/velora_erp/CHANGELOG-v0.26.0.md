# Changelog — VeloraERP 0.26.0

## Fixed Asset Depreciation and Impairment

- Added controlled Fixed Asset Depreciation Run and child line documents.
- Added Straight Line, Reducing Balance and Units of Production methods.
- Added prospective depreciation calculations after impairment and revaluation.
- Added non-overlapping and contiguous depreciation period enforcement.
- Added fixed asset impairment loss and reversal assessments with reversal ceiling tracking.
- Added accumulated impairment account mapping and posting integration.
- Added depreciation policy inputs to Fixed Asset Purchase and Purchase Invoice capitalisation lines.
- Included lessee right-of-use assets in periodic depreciation.
- Extended the Fixed Assets workspace with depreciation and impairment shortcuts.
- Added the v0.24 workspace migration patch.
