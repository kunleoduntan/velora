Velora Governance — Feature Notes

Application scope

  • Governance foundation: entities, settings, skills, calendar, obligations, policies, controls, risks and exceptions.
  • Board management: boards, members, appointments, committees, skills matrix, evaluation, training and succession.
  • Board operations: meetings, agenda, attendance, quorum, papers, packs, minutes, decisions, resolutions, voting and actions.
  • Secretariat: annual returns, corporate events, filings, regulatory correspondence, statutory registers, shareholders, share classes and shareholding entries.
  • Compliance: requirements, assessments, evidence, remediation and regulatory tracking.
  • Policy and ethics: policies, reviews, acknowledgements, conflict declarations and related-party interests.
  • Sustainability: framework/standard mapping, materiality, stakeholders, metrics, data collection, targets, initiatives, risks/opportunities, GHG, reporting, review, revision, publication and distribution.
  • Exception management: analytics, filtering, ownership, timeline, comments/evidence, escalation and management reporting.
  • Automation: reminders, event-triggered updates, daily/hourly scheduler jobs, execution monitoring and retries.

Example records by process

Board process

Board → Board Member → Board Appointment → Board Committee → Board Meeting → Agenda Item → Board Paper → Board Pack → Minutes → Resolution → Board Action.

Compliance process

Regulatory Requirement → Governance Obligation → Compliance Assessment → Compliance Evidence → Filing Requirement → Filing Submission → Corporate Filing → Statutory Register Entry.

Sustainability process

Sustainability Framework → Sustainability Standard → Sustainability Disclosure → Materiality Assessment → Sustainability Metric → Sustainability Data Point → Sustainability Target → GHG Calculation → Sustainability Report → Review → Revision → Publication.

Exception process

Source event → Governance Exception → Governance Exception Activity → assignment/evidence/comment/status history → resolution and closure. Escalation settings are managed by Governance Exception Configuration and use the existing framework approval/workflow services where applicable.

Important boundaries

  • Approval and workflow configuration are framework-native, not duplicated in Governance.
  • SLA engine is external/owned by the existing SLA application. Governance displays provider facts when connected.
  • Live runtime qualification is required before production sign-off: migration, permissions, scheduler, notifications, UI, export, concurrency and backup/restore.
Velora Governance v11.5.0 · Documentation packaged with the application

Added in 11.10.0

  • GWP Set and GWP Value: the IPCC AR5 and AR6 100-year potentials (editable) used to convert gases to CO2e.
  • Emission Factor Gas and GHG Calculation Gas: gas-by-gas factors and the gas breakdown of each calculation.
  • GHG Inventory Setting: organisational boundary, default GWP set, base year and recalculation policy per entity.
  • Governance Code, Governance Code Principle, Code Compliance Assessment and Code Compliance Response: apply-and-explain assessment against the Nigerian Code of Corporate Governance 2018.
  • Spend Emission Rule, Activity Feed Run and Activity Feed Run Result: ERP purchase-invoice spend mapped to emission sources and spend-based factors, with a coverage figure and an audit of each run.
  • Climate Scenario Analysis, Climate Scenario Row and Climate Scenario Impact: the scenario analysis IFRS S2 paragraph 22 asks entities to disclose.
  • Materiality Assessment now scores impact and financial materiality from structured criteria, requires reasons for overrides and non-material topics, and requires board or committee approval to complete. Sustainability Target gains the IFRS S2 paragraph 33 and 36 detail. IFRS S1 and S2 requirements are seeded as Sustainability Disclosures.
  • XBRL Export Setting and Taxonomy Concept Map: the taxonomy entry point, entity identifier and element names that the Inline XBRL export of GHG facts uses. Element names are entered from the taxonomy release you file against; the software does not supply them.

Added in 11.12.0

  • Governance Code Practice and Code Compliance Practice Response: the recommended practices under each of the 28 NCCG 2018 principles (paraphrased, with the Code's reference numbers), answered per assessment with an explanation required for every departure.
  • SASB Industry, SASB Metric, SASB Adoption and SASB Metric Response: the structure for SASB industry metrics. No SASB content is shipped because it is licensed; industries and metrics are loaded from an Excel workbook. Responses fill from linked data points and feed the IFRS S2 paragraph 32 checklist line.
  • Taxonomy Concept Map can now carry data-point figures (number, percentage, monetary) and report-section narrative as Inline XBRL text blocks, with units and scale set by the preparer.
