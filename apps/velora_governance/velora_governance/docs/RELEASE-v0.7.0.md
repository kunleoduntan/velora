# Velora Governance v0.7.0 — Sustainability Reporting Engine

## Scope
- Sustainability Reporting Period master with lifecycle and framework selection.
- Disclosure Assessment register with applicability, data/evidence/narrative completeness, readiness percentage, owner, due date and reviewer.
- Report review register supporting multiple review rounds and roles.
- Generated report content blocks by framework, disclosure, and reporting period.
- Report Generation Log for readiness, assessment and content-generation auditability.
- Deterministic reporting helper service: disclosure readiness, gap analysis and draft block generation.

## Controls
Generated content is explicitly draft and requires human review. Applicability and mappings remain configurable. The release does not represent legal/regulatory compliance or replace framework-specific interpretation. Approval workflow remains framework-native and configuration-driven; no approval logic is hard-coded in this app.

## Next
