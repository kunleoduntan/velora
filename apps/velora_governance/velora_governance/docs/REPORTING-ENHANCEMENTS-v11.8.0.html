Velora Governance v11.8.0

Period Comparison, Trend Analysis and Interactive Drill-down

Reporting enhancements are built on the existing permission-aware report catalogue and API. The 24 existing report definitions are retained.

Comparison modes

  • Previous Period: compares the current date range with the immediately preceding range of equal duration.
  • Year-over-Year: compares the current dates with the corresponding dates one year earlier. Leap-day ranges are safely adjusted.

Comparative metrics

Each metric displays current value, prior value, absolute delta, percentage change, and increase/decrease/unchanged indicator. Group distributions compare the counts by group label, including labels that appear in only one period.

Interactive drill-down

Click chart bars, grouped summary labels or KPI cards to filter the visible report detail rows. Use Clear drill-down to return to the full retrieved result set. Drill-down does not issue an unrestricted query; it operates only on the permission-aware rows already returned.

Security boundaries

  • Report source DocType read permissions are checked.
  • Native permission-aware retrieval remains the source of rows.
  • Date comparison requires a supported date field and both dates.
  • Report limit remains capped at 5,000 rows per period.
  • No approval/workflow/SLA engine duplication.
