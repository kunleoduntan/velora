# Velora Governance — Release 1 Foundation

## Deliverables
- Governance Settings (Single)
- Governance Entity
- Board
- Board Member and profile child tables
- Board Appointment
- Governance Skill catalogue
- Board Skills Matrix and requirements child table
- Governance Calendar Event

## Naming series
The DocTypes use framework-native `series:` autoname defaults. The company Naming Series Rules setting (`naming.rules`) may override patterns by DocType. No app-local counters or numbering engine exist.

## Privacy
Personal director information uses permission level 1. System Manager, Governance Administrator and Company Secretary have full field-level access; other roles have only level-0 access.

## Workflow
The app defines no approval workflow. Governance approval processes must be configured in the shared Velora Workflow Designer.
