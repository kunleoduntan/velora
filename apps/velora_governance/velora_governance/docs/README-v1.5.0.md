# Velora Governance v1.5.0 Release

This package adds operational report review queue services, review issue tracking, immutable report revision snapshots, finalization-readiness checks, and escaped print-friendly HTML assembly.

Review and approval routing remains controlled by the shared, configurable Velora Workflow Engine. The app does not hardcode approval levels, approvers, thresholds, routing, delegation, parallel approval or escalation.

See `RELEASE-v1.5.0.md` and `VALIDATION-v1.5.0.md` for scope and qualification details.
